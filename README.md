# Puzzle-Factory-3D
لعبة ألغاز ثلاثية الأبعاد للهواتف، قيد التطوير باستخدام Unity. تتضمن الشريحة الحالية ثلاث مراحل فرز قابلة للعب في ورشة المصنع.

- المسار المحلي المعتمد هو `C:\Projects\Puzzle-Factory-3D`.
- تحدّد المواصفات v0.2 أول مرحلة تنفيذية بثلاث مراحل احترافية فقط، ثم التوسع إلى 20 مرحلة بعد قبول النسخة المصغرة.
- يُسمح برفع ملفات المشروع وتحديثاتها إلى [مستودع GitHub الحالي](https://github.com/alosha2004/Puzzle-Factory-3D). يتطلب نشر اللعبة على Google Play أو تفعيل الإعلانات أو إجراء أي عمليات دفع موافقة صريحة من المستخدم.
